# React starter

This project was generated with [Set React App](https://github.com/ShubhamSarda/set-react-app). Edit `src/App.jsx` to build your first component and `src/index.css` to change the styles.

## Commands

| Command | What it does |
| --- | --- |
| `npm start` or `npm run dev` | Starts the Vite dev server on port 3000 |
| `npm test` | Runs the starter test in `src/App.test.jsx` |
| `npm run build` | Creates a production build in `dist/` |
| `npm run preview` | Serves the production build locally |
